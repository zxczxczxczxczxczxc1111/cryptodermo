# Что менялось

## 1.1.0 — 17 августа 2026

Большое обновление. Главное в нём — приложение больше не обязательно открывать,
чтобы достать пароль.

### Быстрый доступ по горячей клавише

Появилось маленькое окно, которое открывается сочетанием клавиш поверх любой
программы: набрал несколько букв, Enter — пароль в буфере обмена, Shift+Enter —
логин. У записей с двухфакторкой рядом кнопка для кода. Escape закрывает.

Сочетание выбирается в настройках, раздел «Вызов из системы». Работает, пока
приложение запущено, поэтому там же есть две галочки: сворачивать окно в трей
вместо закрытия (открыл один раз за день и пользуешься клавишами) и запускать
приложение вместе с Windows. Во втором случае оно стартует заблокированным —
база не расшифрована, ключа в памяти нет, по сочетанию сначала спрашивается PIN.

Если приложение закрыто совсем, в меню «Пуск» есть отдельный ярлык
«cryptodermo (быстрый доступ)»: ему тоже можно назначить сочетание средствами
Windows, и он поднимет то же окно с вводом PIN.

Внутри самого приложения то же самое открывается по Ctrl+K из любого экрана.

### Коды двухфакторной аутентификации

Теперь второй фактор можно держать рядом с паролем, и телефон из входа выпадает
совсем. В редакторе появилась кнопка «Код двухфакторки»: вставьте туда ключ,
который сайт показывает рядом с QR-кодом при включении 2FA — либо строку вроде
`JBSW Y3DP EHPK 3PXP`, либо ссылку целиком. В карточке вместо точек будет живой
шестизначный код с обратным отсчётом, а копируется именно код, а не ключ.

Тот же ключ можно оставить и в приложении на телефоне: они не мешают друг
другу, это два одинаковых ключа от одной двери. Всё считается на вашей машине,
без интернета.

Оговорка, которую стоит знать: пароль и второй фактор в одном хранилище — это
полтора фактора, а не два. Для главной почты и банка код надёжнее оставить
только на телефоне.

### Несколько аккаунтов в одной записи

Если у вас три почты на одном сервисе, больше не нужно заводить три записи или
сваливать девять полей в кучу. Кнопка «Добавить аккаунт» в редакторе создаёт
блок со своим логином, паролем и, если нужно, кодом двухфакторки. Поля вне
блоков остаются общими для всей записи — например, адрес сайта.

В карточке аккаунты разделены заголовками, а в быстром поиске каждый виден
отдельной строкой: `gmail · Рабочая · me@gmail.com`.

### Избранное и дублирование

Записи можно закреплять звёздочкой — они всегда наверху списка. И дублировать:
копия открывается сразу в редакторе, удобно, когда у сервиса несколько похожих
учёток.

### Работа с клавиатуры

По списку теперь можно ходить стрелками, Home и End прыгают на края. Enter
открывает запись, Ctrl+C копирует её пароль не открывая, Ctrl+N создаёт новую,
Ctrl+F или просто `/` ведут в поиск, Escape сначала снимает поиск и только потом
выбор. Рядом с каждой строкой появилась кнопка копирования, чтобы не открывать
карточку ради одного пароля.

### QR-код

У каждого значения появилась кнопка с QR-кодом: наводите камеру телефона и
получаете пароль, минуя облака, мессенджеры и историю буфера обмена. Окно
закрывается само через минуту.

### Вложения перетаскиванием

Файл можно бросить в любое место редактора — системный диалог больше не
обязателен. Бросать можно сразу несколько.

### Ссылки открываются в браузере

Поле с адресом сайта теперь открывается одним нажатием.

### Проверка обновлений

В настройках появилась проверка новых версий. **По умолчанию выключена** — это
единственное место, где приложение выходит в сеть, и рядом подробно написано,
что именно уходит: только вопрос к GitHub о номере последней версии, без единого
байта из вашей базы. Скачивание и установка остаются ручными.

### Внешний вид

Приложение получило свою рамку окна вместо системной, круглую иконку, свои
чекбоксы и уплотнённые настройки в две колонки. У всех полей пароля появилась
кнопка «показать» — раньше её рисовала система и показывала не всегда.

### Установщик

Переведён на русский, оформлен в стиле приложения. Находит уже установленную
версию и обновляет её в той же папке, не трогая базу и резервные копии. При
удалении отдельно спрашивает, удалять ли базу паролей, и по умолчанию её
сохраняет. Второй экземпляр приложения больше не запускается.

### Что починено

- Копирование в буфер обмена переведено на системное. Прежнее зависело от того,
  какое окно сейчас в фокусе, и могло молча не сработать — в том числе при
  автоочистке буфера во время блокировки.
- Поля внутри записи различаются по позиции, а не по имени. Раньше в записи с
  двумя аккаунтами кнопка «показать» открывала оба пароля сразу, а копирование
  брало чужой.
- Ячейки PIN больше не дорисовывают лишнюю: верный четырёхзначный код открывает
  базу сразу.
- С экрана мастер-пароля можно вернуться к вводу PIN — раньше это была дверь в
  одну сторону.
- Щелчок в любое место экрана входа возвращает курсор в поле ввода.

## 1.0.0 — 17 августа 2026

Первый релиз: хранилище с шифрованием AES-256-GCM, вход по PIN, вложения,
генератор паролей, история изменений, автоблокировка, резервные копии и
автономный аварийный дешифратор на Python.
