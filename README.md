# cryptodermo

Личный офлайн-менеджер паролей под Windows. Ничего не уходит в сеть, аккаунта
нет, база - один зашифрованный файл рядом с программой.

Tauri v2 + React 19 + TypeScript на фронте, Rust только для файловых операций.

## Установка

**Самый простой способ - портативная версия.** Скачайте `cryptodermo.exe` со
[страницы релизов](../../releases/latest) и положите в любую папку. Устанавливать
нечего, база создастся рядом с файлом, в системе не остаётся ничего. Программу
вместе с базой можно носить на флешке.

Если предпочитаете обычную установку, там же лежит
`cryptodermo_1.1.0_x64-setup.exe`, а для корпоративной - `.msi`. Установщик
находит уже стоящую версию, обновляет её в той же папке и не трогает базу с
резервными копиями.

В обоих случаях Windows SmartScreen покажет предупреждение о неизвестном
издателе: файлы не подписаны сертификатом. «Подробнее» → «Выполнить в любом
случае». Снять предупреждение заранее можно командой
`Unblock-File .\cryptodermo.exe` в PowerShell - оно вызвано меткой «файл скачан
из интернета», а не содержимым файла.

**Дальше, при первом запуске:**

1. Придумайте мастер-пароль. Он нигде не хранится и не восстанавливается:
   забудете - база не откроется ни у кого, включая автора.
2. Приложение предложит настроить PIN-код для повседневного входа. Это не
   второй пароль, а обёртка того же ключа - см. «Как устроена защита».

### Быстрый доступ по горячей клавише

В меню «Пуск» рядом с обычным ярлыком установщик создаёт второй,
«cryptodermo (быстрый доступ)». Он открывает маленькое окно: ввёл PIN, набрал
несколько букв, Enter кладёт пароль в буфер обмена, окно исчезает. Shift+Enter
копирует логин, Escape закрывает.

Чтобы вызывать его откуда угодно, назначьте сочетание клавиш средствами
Windows: правой кнопкой по ярлыку → «Свойства» → поле «Быстрый вызов» →
нажмите желаемое сочетание (например, Ctrl+Alt+C) → «Применить».

Приложение при этом не висит в памяти постоянно: окно запускается по нажатию и
закрывается само через минуту бездействия. После копирования оно прячется
сразу, но процесс доживает до момента, когда буфер обмена очистится сам,
иначе пароль остался бы там навсегда.

Режим работает только с настроенным PIN: мастер-пароль это несколько секунд
на разбор ключа, что противоречит самой идее быстрого доступа.

### Удаление

Деинсталлятор спросит отдельно, удалять ли базу и резервные копии, и по
умолчанию их сохранит. Это не забывчивость: `vault.dat` - единственная копия
всех ваших паролей, а галочку «удалить данные приложения» легко поставить не
глядя, снося версию ради установки следующей.

## Что умеет

- **Записи пяти типов** - пароли, заметки, карты, ключи, прочее. У каждой
  произвольные поля, любое можно пометить секретным: оно скрыто точками, пока
  вы не нажмёте на глаз.
- **Копирование с автоочисткой** - значение исчезает из буфера обмена через
  30 секунд.
- **QR-код** - кнопка рядом с копированием показывает значение кодом, чтобы
  снять его камерой телефона. Ничего не уходит ни в сеть, ни в историю буфера
  обмена; окно закрывается само через минуту.
- **Вложения** - файлы прямо внутри записи, картинки и текст открываются в
  карточке. SVG и PDF намеренно не открываются: их просмотр требует движка,
  исполняющего чужой код внутри окна с паролями.
- **Генератор паролей** с настройкой длины и набора символов.
- **История изменений** - прежние значения секретных полей сохраняются, а поля
  старше года помечаются точкой.
- **Быстрый доступ** - маленькое окно по сочетанию клавиш поверх любой
  программы: несколько букв, Enter, пароль в буфере. Внутри приложения то же по
  Ctrl+K.
- **Несколько аккаунтов в одной записи** - три почты одного сервиса живут
  раздельными блоками со своими логинами, паролями и кодами.
- **Избранное** - закреплённые записи всегда наверху списка.
- **Работа с клавиатуры** - стрелки по списку, Enter открывает, Ctrl+C копирует
  пароль не открывая, Ctrl+N создаёт, `/` ведёт в поиск.
- **Автоблокировка** по бездействию и при сворачивании окна.
- **Коды двухфакторки** прямо в записи: поле со ссылкой `otpauth://` показывает
  живой шестизначный код с обратным отсчётом, копируется код, а не ссылка.
  Считается на месте, без сети, и не мешает тому же секрету жить в приложении
  на телефоне.
- **Проверка обновлений** - единственное место, где приложение выходит в сеть.
  По умолчанию выключена, включается в настройках, где подробно написано, что
  именно уходит.
- **Резервные копии** - последние 20 версий базы в `backups/`, ротация автоматическая.
- **Импорт и экспорт** в JSON, с корзиной на случай ошибочной замены.

Полный список изменений по версиям - в [CHANGELOG.md](CHANGELOG.md).

## Как устроена защита

Ключ выводится из мастер-пароля через PBKDF2-SHA256, 5 000 000 итераций
(рекомендация OWASP - 600 000). Данные шифруются AES-256-GCM средствами
`crypto.subtle`, своей криптографии в приложении нет.

В `vault.dat` открытым текстом лежат версия формата, соль, вектор инициализации
и параметры KDF. Так и должно быть: это входные данные для расшифровки, без них
расшифровать нечем. Секрет ровно один и он не в файле.

PIN-код - не альтернативный пароль. Настоящий ключ базы шифруется отдельным
ключом, выведенным из PIN (своя соль, 600 000 итераций), и результат лежит в
`vault.settings.json`. Три неверные попытки блокируют вход на время; смена
мастер-пароля делает PIN-обёртку недействительной.

## Аварийный дешифратор

Если приложение однажды не запускается или не собирается, а база нужна прямо
сейчас, `emergency-decrypt.py` расшифровывает `vault.dat` (или любой файл из
`backups/`) в обычный JSON, зная только мастер-пароль. Нужен Python 3 и ничего
больше: `pip install` не требуется.

```
python emergency-decrypt.py путь/к/vault.dat
```

Пароль спрашивается интерактивно, при вводе ничего не отображается. Флаг
`--unpack-attachments КАТАЛОГ` дополнительно распаковывает вложения в отдельные
файлы.

Для тех, кто не хочет открывать командную строку, рядом лежит
`emergency-decrypt.bat`: запустите его (или перетащите `vault.dat` на файл),
введите мастер-пароль - результат появится в `vault-decrypted.json` рядом с
базой.

Рядом с `emergency-decrypt.py` обязательно должен лежать `aes_gcm.py` -
собственная реализация AES и AES-GCM (в стандартной библиотеке Python нет ни
одного шифра). Все три файла приложение копирует само при каждом сохранении:
рядом с базой и в каждую резервную копию. Если скопировать только часть
набора, `emergency-decrypt.py`/`.bat` откажут с понятной ошибкой, а не упадут
непонятно как.

## Портативность и синхронизация

`vault.dat` и каталог `backups/` создаются рядом с исполняемым файлом. В
`%AppData%` и реестр не пишется ничего, так что приложение вместе с базой
переносится на флешке.

Сетевой синхронизации внутри нет и не планируется. Но база - один файл, и её
можно положить в папку, которую синхронизирует облачный клиент. Каждое
сохранение атомарно (запись во временный файл, `fsync`, переименование поверх
боевого), поэтому облако всегда видит либо старую версию целиком, либо новую
целиком, но никогда половину.

Чего это НЕ решает - правку на двух устройствах одновременно. Тогда более
позднее сохранение перезапишет более раннее либо клиент создаст файл-конфликт.
Открывайте базу на одном устройстве за раз и дожидайтесь окончания
синхронизации.

## Разработка

| Команда | Что делает |
|---|---|
| `npm install` | Установить зависимости фронта |
| `npm run tauri dev` | Запустить приложение локально (окно + hot reload) |
| `npm run dev:mock` | Открыть интерфейс в браузере на тестовых данных, без Tauri |
| `npm run tauri build` | Собрать `.exe` и установщики под Windows x64 |
| `npm test` | Тесты фронта (Vitest) |
| `npx tsc --noEmit` | Только проверка типов |
| `cargo test` (в `src-tauri/`) | Тесты Rust-части |

Компоненты в тестах не рендерятся: `jsdom` в проекте нет намеренно. Вся логика
принятия решений вынесена в обычные функции без React и DOM и покрыта тестами
напрямую, разметка проверяется сборкой и живым прогоном.
