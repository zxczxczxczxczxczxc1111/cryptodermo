# Vault

Личное офлайн-хранилище зашифрованных записей. Tauri v2 + React + TypeScript
+ Vite на фронте, минимальный Rust-слой (только файловые операции).

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Установить зависимости фронта |
| `npm run tauri dev` | Запустить приложение локально (окно + hot reload) |
| `npm run tauri build` | Собрать `.exe` под Windows x64 |
| `npm test` | Тесты фронта (Vitest) |
| `cargo test` (в `src-tauri/`) | Тесты Rust-части |

## Портативность

По умолчанию `vault.dat` и каталог `backups/` создаются рядом с исполняемым
файлом приложения - ничего не пишется в `%AppData%` или реестр. Это позволяет
носить приложение и базу на флешке.
